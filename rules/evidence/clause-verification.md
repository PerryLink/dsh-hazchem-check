## 一、已取得逐字条文的文件

### 1. 《中华人民共和国危险化学品安全管理条例》（国务院令第 591 号）

- **核验到的版本事实**：由 2011 年 2 月 16 日国务院第 144 次常务会议修订通过，
  2011 年 3 月 2 日公布（总理 温家宝 签署），**自 2011 年 12 月 1 日起施行**；
  原 2002 年 1 月 26 日国务院令第 344 号公布的版本被本次修订取代。
- **来源**：中国政府网 <https://www.gov.cn/zhengce/2011-03/11/content_2602576.htm>（2011-03-11 发布）

逐字条文（与规则相关的两条）：

> **第十九条**　危险化学品生产装置或者储存数量构成重大危险源的危险化学品储存设施（运输工具加油站、加气站除外），与下列场所、设施、区域的距离应当符合国家有关规定……
>
> ……本条例所称重大危险源，是指生产、储存、使用或者搬运危险化学品，且危险化学品的数量等于或者超过临界量的单元（包括场所和设施）。

> **第十五条**　危险化学品生产企业应当提供与其生产的危险化学品相符的化学品安全技术说明书，并在危险化学品包装（包括外包装件）上粘贴或者拴挂与包装内危险化学品相符的化学品安全标签。化学品安全技术说明书和化学品安全标签所载明的内容应当符合国家标准的要求。

**对规则的影响（三处已按条文更正/确认）**：

| 规则 | 原 `note` 的判断 | 核对后的结论 |
|---|---|---|
| `HZ-004` 台账应填写临界量 | "临界量由标准规定" | **确认**。条例第十九条把"重大危险源"定义为"数量等于或者超过**临界量**的**单元**"，故临界量是本制度的核心量，台账不写临界量即无辨识依据。 |
| `HZ-006` 有储存量的记录 SDS 编号 | "SDS 是危险化学品的身份证" | **确认并落到了条文**。条例第十五条要求生产企业提供化学品安全技术说明书且**内容应当符合国家标准的要求**。 |
| `HZ-008` 名称栏无占位符 | "这份台账要拿去做辨识和备案" | **确认**。条例第二十五条要求储存单位建立出入库核查、登记制度，并把构成重大危险源的储存数量、地点、管理人员报安监与公安**备案**。 |

### 2. GB 18218—2018《危险化学品重大危险源辨识》第 4.2 条

- **来源**：中国建筑科学研究院建筑防火研究所 消防规范网
  <http://gf.cabr-fire.com/m/article-27762.htm>（GB 18218-2018 §4.2 全文页）
- ⚠️ 该来源为**第三方规范汇编站点**，非标准发布机构官方站点；条文文本与官方文本的一致性未进一步核验。

逐字条文：

> **4.2.1**　生产单元、储存单元内存在危险化学品的数量等于或超过表 1、表 2 规定的临界量，即被定为重大危险源。单元内存在的危险化学品的数量根据危险化学品种类的多少区分为以下两种情况：
> 　　a）生产单元、储存单元内存在的危险化学品为单一品种时，该危险化学品的数量即为单元内危险化学品的总量，若等于或超过相应的临界量，则定为重大危险源。
> 　　b）生产单元、储存单元内存在的危险化学品为多品种时，按式（1）计算，若满足式（1），则定为重大危险源：
> 　　S = q₁/Q₁ + q₂/Q₂ + ••• + qₙ/Qₙ ≥ 1 ……………………（1）
> 　　式中：S——辨识指标；q₁，q₂，•••，qₙ——每种危险化学品的实际存在量，单位为吨（t）；Q₁，Q₂，•••，Qₙ——与每种危险化学品相对应的临界量，单位为吨（t）。
>
> **4.2.2**　危险化学品储罐以及其他容器、设备或仓储区的危险化学品的实际存在量按设计最大量确定。
>
> **4.2.3**　对于危险化学品混合物，如果混合物与其纯物质属于相同危险类别，则视混合物为纯物质，按混合物整体进行计算。如果混合物与其纯物质不属于相同危险类别，则应按新危险类别考虑其临界量。
>
> **4.2.4**　危险化学品重大危险源的辨识流程参见附录 A。

**对规则的影响（三处，其中一处是规则库原先的判断需要更正）**：

1. `HZ-003` 的多品种校正说明 —— **原文用 `S = Σ qᵢ/Qᵢ ≥ 1`，规则 note 与 README 的表述与之一致**（原先写作
   `Σ(实际量÷临界量) ≥ 1`，现已在规则库头与 README 中改为标准原式 `S = q₁/Q₁ + q₂/Q₂ + … + qₙ/Qₙ ≥ 1`）。
   同时确认临界量出自**表 1、表 2**（不是正文列举），本插件**不内置该表**，故只核对台账自行填写的临界量。
2. ⚠️ **原先"实际存在量应按最大在线量计算"的说法不够准确。** 条文原话是"按**设计最大量**确定"。
   规则库中该处措辞已按条文更正为"按**设计最大量**确定（4.2.2）"。
3. `HZ-003` 的判定粒度得到确认：**辨识的单元是"生产单元、储存单元"**（4.2.1），
   而台账通常按化学品逐个登记、不带单元分组 —— 这正是本插件**做不了多品种求和**的原因，
   规则 note 已把这一点写成"需要按单元分组，而台账通常不这样组织"，与条文口径一致。

## 三、据此确认的规则边界（与 README 一致）

1. **本插件不内置 GB 18218 的临界量表**，只核对台账自行填写的临界量；因此**发现不了"临界量取错了品
   种或类别"**。
2. **本插件不做多品种求和 `S = Σ qᵢ/Qᵢ ≥ 1`**，因为辨识单元是"生产单元、储存单元"而台账按品种登记；
   因此**发现不了"单品种都不超、合起来构成重大危险源"**这一最常见的漏判。
3. **本插件不核对"实际存在量"的取值口径**（4.2.2 要求按设计最大量），台账若填的是库存量，本插件无从分辨。
4. 上述三项都需要按标准逐单元计算，属于安全评价与主管部门认定的事项 —— 这也是本插件全部规则封顶 `warn`
   的原因。
